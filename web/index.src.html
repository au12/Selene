Compare readings from a real GMW-15

Set the real watch to the same GMT offset and whole-degree LO/LA as this one, dial a date in moon time and sunrise/sunset mode, and type what it shows. Leave a field blank if you didn't read it; type - for -:--. Times without a/p are matched to the nearer half of the day.

Keys: B/↑ SET · C/↓/Space MODE (hold 3 s: demo) · D/← REV · A/→ FWD · L light/snooze · 1–3 model.
Moon data computed live in your browser with the engine chosen in Settings; times shown in 5-minute units like the original module.
